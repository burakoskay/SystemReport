## O novo jogo mobile da Cartoon Network

A Cartoon Network lançou seu primeiro jogo mobile sem um programa de TV acompanhado, OK K.O.! Lakewood Plaza Turbo, desenvolvido por Ian Jones-Quartey. O jogo vem com um convite para hackers e desenvolvedores melhorarem e alterarem o jogo como achar melhor. Essa medida faz parte da estratégia da Cartoon Network para impulsionar a expressão criativa e a inovação para sua marca.

A rede planeja expandir além de séries de televisão animadas, com foco em criar mundos animados que podem se desenrolar em qualquer plataforma. Essa medida é vista como um esforço para alcançar crianças que passam mais tempo no Snapchat e jogando jogos iOS do que assistindo TV. De acordo com Rob Sorcher, diretor criativo da Cartoon Network, a rede deseja criar uma plataforma para expressão criativa e inovação.

## O jogo e suas características

OK K.O.! Lakewood Plaza Turbo é um jogo de código aberto que permite aos desenvolvedores modificá-lo e melhorá-lo. A Cartoon Network convidará 200 programadores independentes para um *game jam* em Portland, Oregon, para trabalhar no jogo. O jogo é esperado para ser um sucesso, com a presidente e gerente geral da Cartoon Network, Christina Miller, afirmando que o comportamento de código aberto fala à sua estratégia geral de impulsionar a expressão criativa e a inovação.

O jogo foi construído usando software de código aberto, o que permitirá aos desenvolvedores modificá-lo e melhorá-lo, criando uma abordagem de desenvolvimento de jogos impulsionada pela comunidade. O uso de software de código aberto também permitirá que a Cartoon Network aproveite o conhecimento e a expertise coletiva da comunidade de desenvolvedores.

## Gemini-Overlay-Update
Google rollt Updates für das Gemini-Overlay auf Android aus, nachdem der Neural Expressive-Neudesign auf der I/O 2026 vorgestellt wurde. Das Update umfasst Dynamic Color und die Integration von 'Bildschirminhalten'. Diese Änderung zeigt Googles fortgesetzte Bemühungen, die Android-Oberfläche zu verfeinern, aufbauend auf der Grundlage, die durch das Neural Expressive-Neudesign gelegt wurde.

## Was ist neu
Das Gemini-Overlay auf Android umfasst nun Dynamic Color und die Integration von 'Bildschirminhalten'. Laut Google folgen diese Anpassungen dem Neural Expressive-Neudesign, das auf der I/O 2026 angekündigt wurde. Die Aufnahme von Dynamic Color soll eine persönlichere Erfahrung bieten, indem das System seine Farbschemata basierend auf dem Wallpaper des Benutzers anpasst. Die Integration von 'Bildschirminhalten' verbessert die Funktionalität des Overlays, indem mehr bildschirmbezogene Funktionen integriert werden.

Googles Neural Expressive-Neudesign auf der I/O 2026 führte bedeutende Änderungen an der Android-Oberfläche ein. Die Updates für das Gemini-Overlay sind Teil dieser Änderungen.

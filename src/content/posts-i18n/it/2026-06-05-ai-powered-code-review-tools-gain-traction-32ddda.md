## Open Code Review dell'Alibaba prende forma

L'Alibaba ha rilasciato Open Code Review, un CLI guidato dall'intelligenza artificiale che esegue automaticamente le revisioni dei codici per le richieste di pull. L' tool aggiunge uno stato di controllo a GitHub, segnala i problemi e può suggerire le differenze. Il repository mostra 179 voti a favore e 49 commenti su Hacker News. Il lancio di questo tool non è una sorpresa, considerando la crescente necessità di processi di revisione del codice efficienti.

## Continue automatizza le revisioni dei codici

Continue consente ai sviluppatori di scrivere agenti basati su markdown in una cartella `.continue/checks/`. Ogni file markdown descrive una verifica; un badge verde significa che il codice passa, mentre un badge rosso restituisce un patch suggerito. Continue integra le verifiche di stato di GitHub. Questa approccio consente ai sviluppatori di creare verifiche personalizzate in base alle loro esigenze specifiche.

## av semplifica le PR sovrapposte

av fornisce uno strumento di riga di comando per gestire le richieste di pull sovrapposte su GitHub. Crea richieste di pull dipendenti, traccia i commit base e riebbeanza automaticamente le ramificazioni downstream. Unisciti alla comunità Discord di av: https://discord.gg/TFgtZtN8. Leggi di più su https://rethinkingcode.reviews/with/stacked-prs. Gli strumenti hanno guadagnato popolarità tra i sviluppatori che cercano di ottimizzare il loro workflow.

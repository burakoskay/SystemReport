## AlibabaのOpen Code Review、具体的な形に

Alibabaは、プルリクエスト上で自動的に実行されるAI駆動のCLIであるOpen Code Reviewをリリースした。このツールは、GitHubにステータスチェックを追加し、問題をフラグ付けし、差分を提案することができる。Hacker Newsのレポジトリでは、179の賛成票と49件のコメントが寄せられている。効率的なコードレビュープロセスの必要性が高まっていることから、この開発は驚くべきことではない。

## Continue、コードチェックを自動化

Continueを使用すると、開発者は`.continue/checks/`フォルダにmarkdownベースのエージェントを記述できる。各markdownファイルはチェックを記述するもので、緑のバッジはコードが合格であることを意味し、赤のバッジはパッチの提案を返す。Continueは、GitHubのステータスチェックと統合されている。このアプローチにより、開発者は特定のニーズに合わせたカスタムチェックを作成できる。

## av、スタックされたPRを合理化

avは、GitHub上のスタックされたプルリクエストを管理するためのコマンドラインツールを提供する。依存するPRを作成し、その基本コミットを追跡し、ダウンストリームブランチを自動的にリベースする。avのDiscordコミュニティに参加する: https://discord.gg/TFgtZtN8。詳しくは、https://rethinkingcode.reviews/with/stacked-prsを参照のこと。このツールは、ワークフローを最適化しようとする開発者たちに人気がある。

## これらのツールが重要な理由

これら3つのプロジェクトはすべて、CIパイプラインのエッジでコード品質チェックを行うことをターゲットとしている。AIベースのチェックは、プロジェクト固有のパターンに適応し、具体的な修正を提案できる。早期導入者は、些細な問題に関するコメントが減ったと報告している。AI駆動のコードレビューを統合することで、開発者はより複雑な問題に集中できる。

## 業界の状況

AI支援レビューとスタックPR自動化の融合は、CIシステムがコンパイルやテストだけでなく、さらに多くのことを行う未来を示唆している。コードレビューツールの世界市場は、2025年までに14億ドルに達すると予測されており、2020年から2025年までのCAGRは14.5％となる。GitLab、GitHub、Bitbucketなどの企業はすでにコードレビュー機能に多額の投資を行っている。RustベースのブラウザであるLadybirdなどのプロジェクトは、新しい開発ワークフローを実験している。Ladybirdのアプローチは、最近の記事（https://ladybird.org/posts/changing-how-we-develop-ladybird/）で説明されているように、革新的な開発プロセスの可能性を示している。

## コードレビューツールの歴史

コードレビューツールの概念は、数年前から存在しているが、様々なプロジェクトがプロセスの合理化を試みてきた。GoogleのFlutterとFirebaseのアップデートは、開発者の生産性を向上させることを目的としており、効率的な開発ワークフローの重要性の高まりを示している。2019年、GitHubはコード分析プラットフォームであるSemmleを買収し、コードレビュー機能を強化した。同様に、GitLabは、自動コードチェックやレビュー分析などの独自のコードレビュー機能を統合している。

## 技術的な仕組み

Continueのmarkdownベースのエージェントの使用は、柔軟でカスタマイズ可能なチェックを可能にする。このツールのGitHubステータスチェックとの統合は、開発者にとってシームレスなエクスペリエンスを提供する。Open Code ReviewのAI駆動アプローチにより、ツールはプロジェクト固有のパターンに適応できる。たとえば、Open Code Reviewのモデルは、ヌルポインタ例外やSQLインジェクション脆弱性などの一般的なコーディングエラーを識別することを学習できる。

## 下流への影響

これらのツールが浸透するにつれて、開発者がコードレビューにアプローチする方法に変化が起こると予想される。AI駆動のチェックと自動化されたワークフローにより、開発者はより複雑な問題に集中できるようになる。クラウドプロバイダーはこれらのオープンソースツールに適応する必要があり、新しいパートナーシップや統合につながる可能性がある。たとえば、AWS、Azure、Google Cloudは、これらのツールを既存の開発プラットフォームに統合し、開発者がAI駆動のコードレビューを採用しやすくする可能性がある。

## 注目すべき点

Open Code Reviewの本番レベルのモデルとContinueの統合発表を注目する。avのGitHubでの採用指標と、クラウドプロバイダーがこれらのオープンソースツールにどのように対応するかを監視する。コードレビューの未来は有望であり、AI駆動のツールが先導している。業界が進化するにつれて、自動化されたコードレビューボットやAIを活用したコーディングアシスタントなどの、より革新的なソリューションが出現することが予想される。

## 今後の展開

AI支援レビューとスタックPR自動化の交差点は、コードレビューのさらなる革新につながる可能性が高い。たとえば、より高度なAIモデルが開発され、複雑なコーディングエラーや脆弱性を検出できるようになる可能性がある。また、コードレビューツールとプロジェクト管理ソフトウェアやCI/CDパイプラインなどの他の開発プラットフォームとの統合が、より一般的になる可能性がある。

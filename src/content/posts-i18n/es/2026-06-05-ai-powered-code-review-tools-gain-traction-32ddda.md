## Open Code Review de Alibaba toma forma

Alibaba lanzó Open Code Review, una herramienta de CLI impulsada por IA que se ejecuta automáticamente en solicitudes de extracción. La herramienta agrega una comprobación de estado a GitHub, señala problemas y puede sugerir diffs. El repositorio muestra 179 votos a favor y 49 comentarios en Hacker News. Este desarrollo no sorprende, dada la creciente necesidad de procesos de revisión de código eficientes.

## Continue automatiza comprobaciones de código

Continue permite a los desarrolladores escribir agentes basados en markdown en una carpeta `.continue/checks/`. Cada archivo markdown describe una comprobación; una insignia verde significa que el código pasa, una insignia roja devuelve un parche sugerido. Continue se integra con comprobaciones de estado de GitHub. Este enfoque permite a los desarrolladores crear comprobaciones personalizadas adaptadas a sus necesidades específicas.

## av agiliza solicitudes de extracción apiladas

av proporciona una herramienta de línea de comandos para gestionar solicitudes de extracción apiladas en GitHub. Crea solicitudes de extracción dependientes, rastrea sus confirmaciones base y rebase automáticamente ramas descendentes. Únete a la comunidad de Discord de av: https://discord.gg/TFgtZtN8. Lee más en https://rethinkingcode.reviews/with/stacked-prs. La herramienta ha ganado popularidad entre los desarrolladores que buscan optimizar su flujo de trabajo.

## Por qué estas herramientas importan

Los tres proyectos apuntan a comprobaciones de calidad de código en el borde de la tubería de CI. Las comprobaciones basadas en IA pueden adaptarse a patrones específicos del proyecto y sugerir soluciones concretas. Los primeros adoptantes informan menos comentarios sobre problemas triviales. Al integrar revisiones de código impulsadas por IA, los desarrolladores pueden centrarse en problemas más complejos.

## Historia de las herramientas de revisión de código

El concepto de herramientas de revisión de código ha existido durante años, con varios proyectos que intentan agilizar el proceso. Las actualizaciones de Google para Flutter y Firebase, destinadas a mejorar la productividad del desarrollador, demuestran la creciente importancia de los flujos de trabajo de desarrollo eficientes. En 2019, GitHub adquirió Semmle, una plataforma de análisis de código, para mejorar sus capacidades de revisión de código. De manera similar, GitLab ha integrado sus propias características de revisión de código, incluidas comprobaciones de código automatizadas y análisis de revisión.

## Mecánica técnica

El uso de agentes basados en markdown de Continue permite comprobaciones flexibles y personalizables. La integración de la herramienta con comprobaciones de estado de GitHub proporciona una experiencia perfecta para los desarrolladores. El enfoque impulsado por IA de Open Code Review permite que la herramienta se adapte a patrones específicos del proyecto. Por ejemplo, el modelo de Open Code Review puede aprender a identificar errores de codificación comunes, como excepciones de puntero nulo o vulnerabilidades de inyección SQL.

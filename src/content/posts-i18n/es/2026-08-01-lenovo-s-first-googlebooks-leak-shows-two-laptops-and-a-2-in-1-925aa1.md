## La línea de Googlebook de Lenovo filtrada
Una serie de imágenes confirma que Lenovo está listo para enviar sus primeros dispositivos bajo la marca de Googlebook. El filtrado muestra tres diseños: una laptop tradicional con cierre de goma, un hermano con pantalla más grande y una tableta 2-en-1. Cada dispositivo está diseñado para ejecutar Chrome OS, proporcionando a los usuarios un sistema operativo ligero para aplicaciones web.
## ¿Qué significa la marca Googlebook para el hardware de Chrome OS?
Google presentó el nombre de Googlebook para dar a los dispositivos de Chrome OS una etiqueta reconocible. Ese esfuerzo de rebranding tiene como objetivo aumentar la visibilidad y la adopción de los dispositivos de Chrome OS entre los consumidores.

## Integración de contactos fluida

La aplicación Gemini acaba de lanzar su última integración con Google Contacts, con el objetivo de proporcionar a los usuarios información y respuestas más personalizadas basadas en sus contactos. Se espera que este movimiento mejore la experiencia del usuario aprovechando la información de contacto para ofrecer interacciones más personalizadas. La integración permite a la aplicación Gemini acceder y utilizar la información de contacto del usuario, lo que le permite generar respuestas e información más relevantes para la red personal y profesional del usuario.

## Cómo funciona

Según 9to5Google, la integración utiliza API (*Application Programming Interfaces*) que permiten a diferentes sistemas de software comunicarse entre sí. En este caso, la API de la aplicación Gemini interactúa con Google Contacts para obtener y utilizar la información de contacto. Este proceso se basa en protocolos de transferencia de datos seguros para garantizar que la información del usuario esté protegida. La aplicación Gemini ahora puede sugerir respuestas a mensajes, recordatorios de eventos basados en interacciones de contacto y más.

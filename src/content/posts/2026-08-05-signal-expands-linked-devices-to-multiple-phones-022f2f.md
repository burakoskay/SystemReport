## Introduction to Linked Devices
Signal now lets you link multiple phones to one account using the same phone number. This update extends Signal's existing linking functionality, which previously supported PCs and iPads. The ability to link multiple phones is a significant development, as it allows users to access their messages across all devices, providing greater convenience and flexibility.
## How Linked Devices Work
When linking a new device, you can choose whether to transfer an end-to-end encrypted copy of your previous messages. The process involves linking devices using your phone number. Signal's end-to-end encryption ensures that only the intended recipient can read the messages. This means that even if one device is compromised, the messages on other linked devices remain secure.
## Security Implications
Linking multiple phones to one Signal account has significant security implications. By allowing users to access their messages across all devices, Signal provides greater convenience. However, if one device is compromised, it could put all linked devices at risk. Signal mitigates this risk with end-to-end encryption. The fact that users can choose whether to transfer encrypted copies of previous messages to new devices also helps to minimize the risk of data breaches.

## Technical Mechanics
The technical mechanics behind Signal's linked devices feature are based on a system of end-to-end encryption and secure device linking. When a user links a new device, Signal generates a new set of encryption keys, which are used to secure the messages on that device. This ensures that even if one device is compromised, the messages on other linked devices remain secure. The use of end-to-end encryption also means that Signal itself cannot access the messages, providing an additional layer of security and privacy for users.

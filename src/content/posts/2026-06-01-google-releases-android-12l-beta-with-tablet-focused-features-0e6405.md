## Android 12L beta brings tablet-first features to a limited hardware set

Google released the first Android 12L beta on Thursday. The build runs on generic Pixel devices and the Lenovo Tab P12 Pro. Android 12L is marketed as a large-screen-focused OS, introducing a new split-screen interface and multicolumn app guidelines.

The beta's hardware limitation means most Android users cannot test the new UI on real tablets. Google recommends the Android emulator or a Generic System Image for broader experimentation. The official timeline calls this the first of three beta builds, with a final release later this year.

Android 12L's focus on large screens is a significant shift in Google's tablet strategy. The company has historically struggled to make Android tablets compelling, but with the rise of Chrome OS and the growing popularity of 2-in-1 devices, Google is trying again.

## Samsung forces lockdown mode in One UI

Samsung stripped the manual 'Lockdown' toggle from the One UI power-menu. The security feature now activates automatically whenever the power menu opens. The change removes a discretionary privacy control that some power users relied on for quick device hardening.

The forced lockdown mode disables biometric unlock, hides notifications, and blocks most app interactions. This move is likely to be controversial among power users who value fine-grained control over their device's security settings.

Samsung's decision to force lockdown mode may be seen as a way to simplify the user experience, but it also raises questions about the company's commitment to user autonomy.

## Google releases Android 17 Beta 4.1

Google released Android 17 Beta 4.1 for Pixel devices. This minor update is a bug fixer ahead of the stable launch. The update is a small but important step in the development of Android 17, which is expected to be a major release.

## Third-party Android tools expand the ecosystem

Focido, a social to-do app designed for iPad, added features including comment count updates and fixed premium status. Separately, a Show HN project released an Android client for Apple's App Store Connect, allowing developers to view iOS app data on Android.

The development of niche Android utilities like Focido and the App Store Connect client highlights the growing demand for cross-platform tooling. As the Android ecosystem continues to evolve, we can expect to see more innovative solutions emerge.

## History of Android Security Features

Android has a long history of security features, dating back to the early days of the platform. Over the years, Google has introduced various security features, including lockdown mode, which was first introduced in Android 9.

The development of lockdown mode was a significant step in the evolution of Android security. The feature allowed users to quickly harden their device's security settings, disabling biometric unlock and hiding notifications.

## Technical Mechanics of Lockdown Mode

Lockdown mode is a complex feature that involves significant changes to the device's security settings. When lockdown mode is enabled, the device disables biometric unlock, hides notifications, and blocks most app interactions.

The technical mechanics of lockdown mode are designed to provide an additional layer of security for users. By disabling biometric unlock and hiding notifications, lockdown mode makes it more difficult for attackers to access sensitive information on the device.

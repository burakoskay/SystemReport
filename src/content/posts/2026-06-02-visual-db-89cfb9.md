## Introduction to Visual DB
The rise of no-code and low-code solutions has made it easier for non-technical users to create and manage databases. One such solution is Visual DB, a web front end for your database that allows users to create professional databases, forms, sheets, and reports with drag-and-drop tools instead of custom code.

Visual DB aims to simplify the process of building basic CRUD applications, which can take weeks to develop. With Visual DB, users can design professional forms, sheets, and reports effortlessly and deploy them in minutes, not weeks.

## Key Features of Visual DB
One of the key features of Visual DB is its ability to create professional data entry forms in minutes with AI assistance. The AI accelerates form layout by automatically placing fields, grouping related fields, and adding section titles. Users can fine-tune the layout manually if needed, and smart guides appear dynamically as you move objects around, showing alignment and spacing cues relative to other objects on the form.

Visual DB also supports master-detail forms, which are a natural and convenient way to view and edit data organized in one-to-many or many-to-many relationships. The platform makes building master-detail forms simple and intuitive, with no coding required.

## Visual DB Sheets and Reporting
Visual DB Sheets offers a familiar spreadsheet interface while storing data in a centralized relational database. Users can edit data as they would in Excel, but with added safeguards such as built-in validation, controlled multi-user access, and a single source of truth that eliminates conflicting files and manual merges.

Reporting is also built-in, allowing business users to find answers and insights without leaving the platform. Reports can be customized on the fly by grouping, filtering, and sorting, and users can apply query parameters to focus on exactly the data they need.

## Creating and Managing Database Schema
Visual DB includes everything needed to create tables and set up relationships without switching tools. Users can browse schemas, view table data, and explore visual diagrams that show how tables are connected. The platform also allows users to create or drop tables, add or remove columns, and define relationships with just a few clicks.

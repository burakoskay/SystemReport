## The Rise of Citizen Science and Game Development

In a related note, researchers from UC Santa Cruz and SRI International have developed a game called Binary Fission, which aims to improve the security of critical software by engaging citizen scientists. The game allows players to sort colored particles, representing values of variables inside the software, into separate pools using filters.

## The Bug in Private Relay
A report notes that the bug in Private Relay causes it to leak users' real IP addresses. The report does not specify the bug's frequency or commonality. Apple's implementation of Private Relay involves routing user traffic through two servers, one run by Apple and another by a third-party partner. This dual-server architecture is intended to add an extra layer of privacy protection by ensuring that neither server has both the user's IP address and the website they are visiting.

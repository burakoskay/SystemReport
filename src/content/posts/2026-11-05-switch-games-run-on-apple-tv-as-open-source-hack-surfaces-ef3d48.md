A Redditor’s Claude Code port now runs Switch titles on Apple TV, proving the streaming box can double as a handheld console.

The project, posted on Reddit, already supports *Super Mario Odyssey* and *Animal Crossing: New Horizons*, with work under way on *The Legend of Zelda: Tears of the Kingdom*.[^1][^3] Both original Switch and the newer Switch 2 binaries load directly, bypassing any cloud‑streaming layer.[^1][^2][^3] The code is open‑source, meaning anyone can inspect, modify, or re‑compile it for their own Apple TV.[^1][^2][^3]

## The Claude Code port in practice

The port leverages Apple TV’s ARM‑based processor to execute the Switch’s native code.[^1] Rather than translating graphics over a network, the project feeds the console’s GPU commands straight to the TV’s hardware.[^1] That approach trims latency to a level that feels comparable to playing on a handheld.[^1]

Because the implementation runs on the device itself, the usual bottlenecks of remote play disappear. Users report smooth frame rates in *Super Mario Odyssey* and *Animal Crossing*, even when navigating complex scenes.[^1][^3] The developers attribute the performance to Apple TV’s unified memory architecture, which mirrors the Switch’s own memory layout closely enough to avoid costly emulation tricks.[^1]

## Nintendo’s sales stumble after price hike

Nintendo reported a near‑40 percent drop in Switch 2 sales after the company raised the console’s price.[^4][^5][^6][^7][^8] The same earnings release highlighted a higher profit margin, suggesting the price bump rescued the bottom line but shredded volume.[^5][^6][^7][^8]

Analysts note that the price increase came at a time when competitors were tightening supply.[^6] The sales dip signals that price elasticity remains a potent force in the console market, especially for a device that sits between a budget handheld and a full‑size home system.[^4][^5] Nintendo’s decision to press ahead with a higher‑priced model may force the company to lean on software revenue to offset weaker hardware uptake.[^7]

## Sony’s supply squeeze contrasts Nintendo’s woes

Sony’s latest quarterly report showed an uptick in PS5 game sales, but the hardware side still battles chronic shortages. Even as developers push new titles, the console remains scarce on retailer shelves.

The contrast highlights divergent strategies: Sony leans on a robust software pipeline while wrestling with supply‑chain constraints, whereas Nintendo’s hardware sales have eroded despite a healthier profit margin. Both firms face the same market pressure—price‑sensitive consumers—but their outcomes diverge sharply based on inventory realities.

## What this means for the console ecosystem

The Claude Code port blurs the line between dedicated gaming hardware and general‑purpose media devices.[^1][^2] If Apple TV can host Switch binaries reliably, developers may start targeting a broader array of ARM platforms, reducing the need for proprietary consoles.[^1]

Nintendo’s sales slump could push the company to explore software‑first strategies, perhaps embracing cross‑platform compatibility more aggressively.[^8] Meanwhile, Sony’s supply crunch reinforces the value of a flexible ecosystem where games can run on multiple devices without forcing a hardware purchase.

## What to watch

Track the next commit to the Claude Code repository for additional Switch 2 titles.[^1][^2][^3] Keep an eye on Nintendo’s pricing announcements for the Switch 2, especially any adjustments aimed at recapturing volume.[^6][^7] Finally, monitor Sony’s supply‑chain briefings for clues on when PS5 inventory will stabilize, as that will shape the competitive dynamics for all three players.
